# 伪造聊天（图片版）

把多段对话渲染成 QQ 风格的聊天截图。官方机器人不支持合并转发，所以改为本地渲染 PNG 再发送。

## 指令

```
/伪造聊天@某人 内容|@另一个人 内容
```

也可以保留旧写法：

```
/伪造聊天 123456#昵称 内容|654321#昵称 内容
```

> 指令与 `@` 之间**不需要空格**；每段之间用 `|` 分隔。

## 示例

```
/伪造聊天@晨喵 阿罗娜今天有点奇怪|@白子 她是不是又在偷看老师
```

出图效果：

```
[头像] 晨喵
       阿罗娜今天有点奇怪
[头像] 白子
       她是不是又在偷看老师
```

## 用法细节

| 写法 | 说明 |
|---|---|
| `@某人 内容` | 推荐。头像、昵称自动取 |
| `123456#昵称 内容` | 旧格式，QQ 号决定头像，昵称手填 |
| `|` | 分隔多条消息，前后不需要空格 |
| `@机器人 /伪造聊天@某人 内容` | 可以，机器人自己的 @ 会被忽略 |

## 昵称与头像

| 元素 | 来源 |
|---|---|
| 昵称 | @ 消息自带 → 群内发言缓存 → `群友XXXX` 兜底 |
| 头像（官方 bot） | `q.qlogo.cn/qqapp/{appid}/{openid}/0`，需要配置 `qq_appid` |
| 头像（NapCat） | `q1.qlogo.cn/g?b=qq&nk={QQ号}&s=100` |

> 被 @ 的人如果从没在群里说过话，昵称只能显示 `群友XXXX`，说一句后再试即可。

## 配置

| 配置项 | 默认 | 说明 |
|---|---|---|
| `self_qq` | 空 | 谁的消息显示在右侧（绿色气泡）；留空用发指令的人 |
| `qq_appid` | 空 | 官方 bot 的 AppID，用于拉取 @ 用户头像 |
| `max_messages` | 20 | 单次最多渲染多少条 |

## 技术说明

QQ 官方 bot 不会把 @群友 解析成 AstrBot 的 `At` 组件，而是在消息文本里保留
`<@!openid>` 标记。插件同时兼容三种来源：

1. AstrBot `At` 组件（OneBot / 部分适配器）
2. 官方文本标记 `<@!openid>` / `<@openid>` / `<@openid@name>`
3. 旧格式 `QQ号#昵称`

## 常见问题

**Q：提示“格式不对”？**
检查每段是不是都写了内容；`|` 前后有空段会被跳过，但整段没有内容会报错。

**Q：头像不是我？**
官方 bot 未配置 `qq_appid` 时会退回首字头像。

**Q：别人的名字显示成群友？**
对方还没在群里发过言，昵称缓存里没有。让他随便说句话即可。

**Q：能伪造多少条？**
默认 20 条，可在配置里调整。
